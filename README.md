# rag-document-chatbot in creation
RAG-powered PDF Q&amp;A chatbot using LangChain + Gemini API + FAISS | Deployed on Streamlit
Phase 1 — Reliable RAG
Source citations, page references, multiple PDFs, conversation history, and a clear fallback when the answer isn't in the documents.



Phase 2 — Smarter Retrieval
Hybrid search, metadata filtering, query rewriting, reranking, and configurable chunking.



Phase 3 — Evaluation
Create 30–100 question-and-answer test cases. Measure retrieval quality, answer correctness, citation accuracy, latency, and cost. Document a baseline and improvements.



Phase 4 — Product Polish
Professional interface, document library, dark/light theme, export, useful empty states, error handling, and a clean public demo.
